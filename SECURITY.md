# Security

Found a vulnerability? Please report it **privately**: this repository's **Security** tab →
**Report a vulnerability**. Never open a public issue for it - an open issue is a public
announcement before there is a fix.

Say what you found, how to reproduce it, and what it lets an attacker do. You get an answer
within a week, and credit in the fix if you want it.

Only the version running on the live site is supported.
