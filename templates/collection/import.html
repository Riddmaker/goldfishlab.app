Three things worth knowing

Any CSV or TSV will do. Columns are read by what they mean, not by which site wrote them, so an export from a tool nobody here has heard of works the same as a familiar one. If a column cannot be placed you are shown the file and asked, before anything is imported.

This replaces what is here. An import is you saying "this is what I own now". Merging would make a corrected re-import silently additive and turn four Swamps into eight.

A row that matches nothing is reported, never dropped. The count comes back on the next screen, so a collection that imported eleven cards short says so rather than quietly being eleven cards short.
