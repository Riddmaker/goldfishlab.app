{% translate "Ramp counts, a little" %}

{% blocktranslate trimmed %} These numbers count lands only. Cheap ramp - a two-mana rock, a spell that fetches a land - makes mana too, but it has to be drawn and cast first, and it cannot be your land for the turn. Decks with a lot of it are often built with a land or two fewer. Whether that holds for yours is a question a simulation answers better than a rule. {% endblocktranslate %}

{% translate "How this was measured" %}

{% blocktranslate trimmed with games=games|intcomma turns=turns %} Each version was played {{ games }} times for {{ turns }} turns with the multiplayer draw rule and the site's usual mulligan rule. The precons are the ones the engine reads best, so their spells are played as written. For more lands, the most expensive cards that are not lands left and basic lands came in, in the deck's own proportion. For fewer lands, basic lands left and second copies of the deck's own two- and three-mana spells came in - a shortcut that breaks the one-copy rule but keeps the deck's curve. {% endblocktranslate %} {% include "core/_why.html" with anchor="games" dark=True %}
