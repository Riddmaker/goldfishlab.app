Where to get it

  • Archidekt: open the deck → More → Export → CSV
  • Moxfield: open the deck → More → Export → copy, then paste it here
  • ManaBox: open the deck → ⋮ → Export
Why not an Excel file?

An .xlsx file is a zip archive and an .xls file can carry macros - a large parser run over a stranger's upload for no benefit you would notice. Every tool that exports a spreadsheet also exports a CSV.
